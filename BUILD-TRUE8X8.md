# MoonMarker True 8×8 x86 build

This temporary build branch produces the MoonMarker `UnitXP_SP3.dll` only.

- Baseline: DreamAvatar v0.3.4 Hotkeys10 system icons FuBar `/daty` native source.
- Native marker capacity: 8 colors × 8 raid icons = 64 independent slots.
- DreamAvatar application behavior is not changed by this build scope.
- DreamWeapon is not included.
- Output architecture: PE32 x86.
