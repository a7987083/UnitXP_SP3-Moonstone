# HFASign v3

HFASign v3 uses the open-source Ksign/Feather architecture and is distributed under GPL-3.0.

Alpha 1 keeps the IPA/TIPA library, Files/share-sheet import, certificate management,
metadata and icon editing, tweak injection, Zsign signing, modify-only mode, installation,
sharing, download management, and logs. Built-in third-party sources, bundled certificates,
donation, Telegram, and Discord promotion are disabled.

HFAPatch JSON/RVA features are intentionally deferred to a later phase.
